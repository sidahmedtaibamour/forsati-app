# فرصتي | FORSATI

موقع/تطبيق يجلب الفرص تلقائيًا كل 6 ساعات، ويحذف المنتهية، ويعرضها بثلاث لغات.
لا خادم ولا قاعدة بيانات ولا ذكاء اصطناعي مدفوع: GitHub يجلب ويحفظ، وGitHub Pages يعرض.

## المراحل (لا تنتقل لمرحلة قبل نجاح السابقة)

### المرحلة 1 — رفع الملفات
1. فك الضغط بـ ZArchiver.
2. في GitHub أنشئ مستودعًا باسم FORSATI من نوع Public.
3. Add file ← Upload files ← اختر كل الملفات (لا توجد مجلدات) ← Commit.
✅ النجاح: ترى الملفات في المستودع.

### المرحلة 2 — ملف النشر والجلب التلقائي
1. Add file ← Create new file.
2. في خانة الاسم اكتب بالضبط: `.github/workflows/site.yml`
3. افتح `site-workflow.yml`، انسخ محتواه كاملًا، والصقه، ثم Commit.
✅ النجاح: تظهر تبويبة Actions في المستودع.

### المرحلة 3 — تفعيل النشر
1. Settings ← Pages ← Build and deployment ← Source: اختر **GitHub Actions** (لا تختر Deploy from a branch).
2. Settings ← Actions ← General ← Workflow permissions ← **Read and write permissions** ← Save.
3. Actions ← **Collect and publish** ← Run workflow.
4. بعد 2 إلى 3 دقائق يظهر في Settings ← Pages الرابط: `https://اسمك.github.io/اسم-المستودع/`
✅ النجاح: يفتح الموقع. كل تشغيل (كل 6 ساعات، أو عند أي تعديل على الملفات) يجلب الفرص وينشر الموقع. ولا ينشر إلا ملفات الصفحة، فلا تظهر `collect.mjs` ولا `sources.json` على الموقع.

### المرحلة 4 — أول جلب
Actions ← Collect opportunities ← Run workflow. بعد دقيقة افتح `status.json`:
- `ok: true` وعدد `fetched` أكبر من 0 = المصدر يعمل.
- `ok: false` أو `error` = الرابط ليس RSS صحيحًا، عدّله أو عطّله.
إن فشلت كل المصادر يفشل التشغيل ويصلك بريد من GitHub.
✅ النجاح: تظهر الفرص في الموقع.

### المرحلة 5 — مصادرك الجزائرية (الأهم)
عدّل `sources.json` وأضف مواقع جزائرية. أغلب مواقع ووردبريس تعطي الخلاصة بإضافة `/feed/` لرابط الموقع؛ افتحه في المتصفح، فإن رأيت كودًا XML فهو يعمل. ضع المصدر بسطر جديد وتصنيفه (jobs, education, scholarships, competitions, training, tools).

### المرحلة 6 — الحسابات (Supabase)
1. supabase.com ← مشروع مجاني جديد.
2. SQL Editor ← الصق `schema.sql` ← Run.
3. Project Settings ← API ← انسخ Project URL وanon key إلى أول سطرين في `auth.js`.
4. Authentication ← URL Configuration ← ضع رابط موقعك في Site URL وRedirect URLs.
5. Authentication ← Sign In / Providers ← **اترك Confirm email مفعّلًا** (مهم للأمان).
6. (اختياري) Providers ← Google لتفعيل الدخول بجوجل. البريد وكلمة المرور يعملان بدونه.
بعدها: تتزامن المحفوظات والإعدادات بين الأجهزة، ويظهر للمستخدم «لوحة التحكم» في «حسابي».

## قبل النشر: سياسة الخصوصية
بريد التواصل (sidahmedtaibamour@gmail.com) موضوع في `privacy.html` وفي تبويب «عن فرصتي». الصفحة مطلوبة عند الدخول بـ Google ولأي نشر لاحق على المتجر.

## الأمان المدمج
- سياسة أمان المحتوى (CSP) داخل `index.html` تمنع تشغيل أي سكربت من خارج موقعك وخارج مكتبة الحسابات.
- كل نص قادم من المصادر يُنقَّى قبل العرض، وروابط الفرص تقبل HTTPS فقط وتفتح بـ noopener.
- مفتاح Supabase المكتوب في `auth.js` (anon) علني بطبيعته؛ الحماية الحقيقية في سياسات RLS داخل `schema.sql`: كل مستخدم يصل لمحفوظاته فقط. **لا تضع أبدًا مفتاح service_role في أي ملف.**
- لا توجد أسرار في المستودع، والجلب لا يحتاج أي مفتاح.
- GitHub Pages لا يسمح بترويسات HTTP مخصصة، لذلك CSP موضوعة كوسم meta.

## المصادر الرسمية (وزارات وشركات)
المصادر من نوع `html` في `sources.json` تقرأ الروابط من الصفحة الرئيسية للموقع لأنه لا يملك RSS.
- هي أقل دقة من RSS، ولا تقرأ مواقع تعتمد على جافاسكربت بالكامل.
- بعض المواقع الحكومية تحجب الاتصال من خارج الجزائر، وخوادم GitHub في أمريكا، فقد تفشل. انظر `status.json`.
- أضف رابط صفحة الإعلانات نفسها (مثل صفحة «التوظيف») بدل الصفحة الرئيسية لنتيجة أفضل.

## كيف تُحذف الفرص المنتهية؟
- إن وُجد تاريخ (آخر أجل / date limite / deadline) في الإعلان تُحذف بعده.
- وإلا تُحذف بعد مدة حسب النوع (وظائف 45 يومًا، مسابقات 30، تدريب 60، منح وتعليم 120، أدوات 180).
- استخراج التاريخ آلي وقد يخطئ أحيانًا، وزر المصدر دائمًا يفتح الإعلان الأصلي.

## ملاحظات

## ما الجديد في الإعدادات ولوحة المستخدم
- زر الإعدادات (الترس): اللغة، الوضع الليلي (تلقائي/فاتح/داكن)، حجم الخط، اختيار ما تريد رؤيته (وظائف فقط، أو التعليم فقط، أو كل الفرص...) والدولة الافتراضية. تُحفظ على الجهاز، وعند تسجيل الدخول تتبعك على كل أجهزتك.
- لوحة التحكم (من «حسابي» بعد الدخول): محفوظاتك، الجديد لك، ما ينتهي خلال أسبوع، وربط Google.
